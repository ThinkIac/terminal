# terminal

Terminal real (PTY via xterm.js sobre WebSocket) com perfis isolados por $HOME

Repositório: https://github.com/ThinkIac/terminal.

## Uso no ThinkIac

Este pacote foi extraído de `packages/terminal`. Preserve a identidade `terminal` do manifest ao instalá-lo em um workspace Lógos. Views, rotas, ferramentas e hooks são descobertos pelo runtime e dependem dos provedores correspondentes. Esta extração publica o código atual; não converte JavaScript para LógosType nem implementa instalação por perfil.

Entrada declarada: `index.js`.

## Dependências e validação

Dependências declaradas: `@xterm/addon-fit`, `@xterm/xterm`, `node-pty`.

O pacote não declara scripts npm de build/teste. Os testes existentes acompanham o fonte; a composição completa requer o host ThinkIac.

## Segurança e dados locais

Credenciais devem ser configuradas no ambiente de destino. Não acompanham esta extração bancos, sessões, uploads, perfis pessoais, arquivos `.env`, caches ou backups. As exclusões foram registradas em relatório externo à publicação. Configure segredos pelo host, sem incluí-los em commits.
